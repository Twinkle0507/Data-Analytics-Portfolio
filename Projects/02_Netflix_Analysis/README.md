# Netflix Data Analysis

## Objective
Analyze the Netflix dataset to understand content trends, genres, countries, ratings, and release patterns.

## Dataset
Netflix Movies and TV Shows Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
- Movies vs TV Shows
- Content by Country
- Top Genres
- Rating Distribution
- Content Added Over the Years
- Release Year Analysis

## Conclusion
This analysis provides insights into Netflix's content library, including popular genres, content distribution across countries, ratings, and release trends.
