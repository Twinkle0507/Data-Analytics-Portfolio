# IPL Data Analysis

## Objective
Analyze IPL match data to discover team performance, player statistics, and tournament insights.

## Dataset
Indian Premier League (IPL) Matches Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
- Matches Won by Teams
- Toss Decision Analysis
- Top Run Scorers
- Top Wicket Takers
- Venue-wise Match Statistics
- Season-wise Performance

## Conclusion
The analysis highlights team performance, player achievements, toss impact, venue statistics, and overall trends across IPL seasons.
